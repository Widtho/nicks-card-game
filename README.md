# Nick's Card Game

A fun MMORPG-style card combat game.

## How to Play
- Each player gets 25 random cards from their 40-card deck.
- Equip gear and abilities to your character.
- Battle turn-based with attack/defense flips.
- First to reduce opponent's HP to 0 wins.

Built with Flask. Playable locally or deployed.

Current version: PAv2.0
